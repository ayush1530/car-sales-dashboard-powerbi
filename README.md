 🚗 Car Sales Dashboard

An interactive Power BI dashboard analyzing **23,906+ car sales records**, covering customer demographics, dealer performance, brand/model trends, and regional sales patterns.

## 📊 Overview

This project explores a large-scale car sales dataset, focusing on:
- Sales trends by brand, model, and company
- Dealer-wise performance comparison
- Customer demographic breakdown (gender, income)
- Regional performance across states/dealers
- Vehicle attribute analysis (engine type, transmission, color)

## 🛠️ Tools & Tech

- **Power BI** — Dashboard design, DAX measures, data modeling
- **Excel** — Data preparation and exploration

## 📁 Files in this Repo

| File | Description |
|------|-------------|
| `Car_Sales_Dashboard.pbix` | Power BI file with the full interactive dashboard |

## 🔍 Key Insights

- Identified top-performing car brands and models by sales volume
- Compared dealer performance to highlight high-volume dealers
- Analyzed customer demographics (gender, income bracket) against purchase patterns
- Surfaced regional sales trends across dealer locations

## 🚀 How to View

1. Download `Car_Sales_Dashboard.pbix`
2. Open in [Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/downloads) (free)
3. Explore the interactive filters, slicers, and drill-through views
